## 2. 신규 화면 프롬프트

### P-01 — 회원가입 (S2)

```
"회원가입" 화면을 만들어라. 프레임명 S2-signup.

[구조: 위 → 아래]
1. 좌상단 뒤로 버튼. 원형 38px, 배경 rgba(255,255,255,0.6) + blur, 테두리 1px rgba(255,255,255,0.75),
   안에 왼쪽 화살표 아이콘 13px #1F5138. 터치 영역은 44×44.
2. 뒤로 버튼 우측 12px 간격에 제목 "회원가입" (H2 24/700).
3. 제목 아래 4px: 힌트 "자율생활부 코드가 있어야 신청할 수 있습니다" (11px, rgba(20,53,38,0.70)).
4. 24px 간격 후 glass 카드. radius 24, padding 22px 20px. 내부 요소 세로 gap 12px.
   입력 5개(모두 input 스타일, placeholder만 다름):
   - "이름"
   - "학교 이메일 (@dshs.kr)"
   - "비밀번호 (8자 이상)"
   - "비밀번호 확인"
   - "가입 코드 (예: DJSN-2691)"  ← 이 입력만 글자 자간 0.1em, 대문자 표시
   마지막 입력 아래 4px 추가 여백 후 주 버튼(가로 100%) 라벨 "가입 신청".
5. 카드 아래 18px: 중앙 정렬 13px "이미 계정이 있나요? 로그인"
   ("로그인"만 700 굵기 #2E6B4C).
6. 그 아래 8px: 중앙 정렬 11px rgba(20,53,38,0.70)
   "가입 시 이름과 학교 이메일이 자율생활부 운영에 사용됩니다".

[변형 4개를 나란히 배치]
A. 기본 (빈 입력, 버튼 비활성 = 투명도 0.45)
B. 입력 완료 (버튼 활성)
C. 에러 — 이메일 입력 테두리 1px #C0392B, 그 아래 6px 간격에 11px #C0392B 문구
   "@dshs.kr 계정만 사용할 수 있습니다"
   동시에 카드 최상단에 높이 40 radius 12 rgba(192,57,43,0.10) 배너,
   12/700 #C0392B "가입 신청에 실패했습니다. 잠시 후 다시 시도해 주세요"
D. 제출 중 — 버튼 라벨 자리에 흰색 스피너 18px, 광택 스윕 정지, 입력 전체 투명도 0.6

[모션 노트] 진입 시 카드 rise 0.5s, 입력 포커스 시 테두리가 #2E6B4C로 0.15s 전환.
```

### P-02 — 승인 대기 / 거절 (S2-1)

```
"승인 대기 안내" 화면을 만들어라. 프레임명 S2-1-pending. 하단 탭 없음. 전체 세로 중앙 정렬.

[변형 A: 승인 대기 (기본)]
1. 중앙 상단에 원형 96px glass 뱃지. 안에 모래시계 선형 아이콘 34px #1F5138.
   원 테두리 바깥에 반경 8px 퍼지는 rgba(31,81,56,0.10) 글로우.
2. 28px 간격 후 제목 "가입 신청이 접수되었습니다" (H2 24/700, 중앙, 2줄 허용).
3. 12px 후 본문 "부장이 승인하면 바로 이용할 수 있습니다." (15/500, rgba(20,53,38,0.70), 중앙).
4. 8px 후 보조 "승인 결과는 이 화면에서 자동으로 반영됩니다." (11px, rgba(20,53,38,0.70), 중앙).
5. 20px 후 상태 칩: radius 999, 틴트 배경, 좌측 6px 초록 점(깜빡임) + 11.5/700 #1F5138 "승인 대기 중".
6. 화면 하단 고정 영역(하단 safe-area + 26px):
   - neu 버튼 가로 100%, padding 15, radius 15, 라벨 13/700 #1F5138 "승인 확인"
   - 12px 아래 텍스트 버튼 "로그아웃" (13/700, rgba(20,53,38,0.70), 중앙)

[변형 B: 거절됨]
- 원형 뱃지 안 아이콘을 느낌표로 교체, 아이콘·글로우 색을 #C0392B 계열로.
- 제목 "가입이 거절되었습니다"
- 본문 "부장에게 문의한 뒤 다시 신청해 주세요."
- 상태 칩 제거.
- 하단 버튼을 주 버튼(그라디언트)으로 교체, 라벨 "다시 신청하기". 그 아래 "로그아웃" 유지.

[변형 C: 확인 중]
- "승인 확인" 버튼 라벨 자리에 #1F5138 스피너 18px.
```
