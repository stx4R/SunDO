## 확정된 결정
- **라우터는 `react-router` 단일 패키지다(v8.3.0).** (W-05 §4-3)
  `react-router-dom`은 v7부터 재수출 껍데기다. 설치하지 마라.
- **`AppShell`이 라우트 루트에 1개, 그 안에 `ToastProvider` 1개, 바깥에 `AuthProvider` 1개다.** (W-05 §4-2)
  화면마다 `AppShell`·`ToastProvider`를 두면 전환할 때 토스트가 사라진다(W-03C §7-5).
  `hasDock`은 라우트 `handle`에서 읽는다.
- **`AuthProvider`는 `router.tsx`의 `RootLayout` 안에 있다.** (W-05 §4-6)
  스플래시 오류 화면의 `다시 시도`가 `key`를 바꿔 재마운트해야 하기 때문이다.
  `window.location.reload()`를 쓰지 마라 — 서비스 워커가 없어(W-16) 오프라인에서 앱이 통째로 사라진다.
- **독은 `DockRootContext`로 스테이지에 포털한다.** (W-05 §4-2)
  `.dock`은 `absolute`라 스테이지 기준이어야 하는데 `DockLayout`이 반환하는 트리는 스크롤 영역 안이다.
  오버레이 루트를 재사용하지 마라 — `pointer-events: none`이라 탭이 죽고, 독은 딤(z-40) **아래**다.
- **`ScreenTransition`(`blurIn`)은 `DockLayout`보다 안쪽에 둔다.** (W-05 §4-4)
  바깥에 두면 탭 이동마다 독이 재마운트되어 활성 알약의 가로 슬라이드가 죽는다.
  **`blurIn`은 `fill-mode: both`라 끝난 뒤에도 `filter: blur(0)`이 남는다** —
  래퍼가 절대 위치 자손의 컨테이닝 블록이 된다. 화면 안 `absolute`는 스테이지 기준이 아니다.
- **상태 리다이렉트는 조용히, 역할 리다이렉트만 TS-12 토스트다.** (W-05 §4-5)
  모든 리다이렉트에 토스트를 붙이면 미인증 사용자가 앱을 열 때마다 `접근 권한이 없습니다`가 뜬다.
- **N-04 vs §8.5.3 충돌은 나눠서 처리했다.** (W-05 §4-1)
  `grade` 형식 오류 → `/`, `classNo` 형식 오류 → `/grade/:grade`. 둘 다 TS-13.
  N-01(한 단계 상위)의 정신을 따랐다. **N-04를 근거로 되돌리지 마라** — 요약으로 본다.
  경로 파라미터는 `Number()`가 아니라 `/^\d+$/`로 읽는다(`Number(' 2 ')`는 2다).
- **`pulseDot`은 design 10a(1.4s ease-in-out)가 아니라 PRD §7.4(1.6s ease)다.** (W-05 §5.2)
  design 안에서도 1.4s는 7곳 중 1곳뿐이다. 지연 스태거 `0/.2/.4s`만 design을 따랐다.
- **`lastActiveAt`만 쓰고 `updatedAt`은 올리지 않는다.** (W-05 §4-8)
  접속을 "프로필 변경"으로 기록하면 `updatedAt`이 DR-12 동기화 신호와 섞여 구분 불가능해진다.
  쓰기 실패 시 스로틀 창을 되돌린다.
- **디자인 원본은 `design/index.html`이다.** (2026-08-20 사용자 확정)
  리셋 전 원격에 있던 `index.html`은 커밋이 더 나중이었으나 **채택하지 않는다.**
  "최신본 채택" 규약을 이 파일에 적용해 원격본을 다시 꺼내오지 말 것.

## 참고
- **`src/App.tsx` 스토리 페이지는 W-05에서 사라졌다.** 필요하면 `git show 1e06962:src/App.tsx`.
  `App.tsx` 주석에도 같은 명령을 적어 뒀다. 되돌리기 비용은 한 줄이다.
- **`AuthProvider`는 `users/{uid}`를 `getDoc` 1회로 읽는다. 구독이 아니다.** (W-05 §6)
  역할 변경이 실시간 반영되지 않는다. R-06의 `getIdToken(true)` + 재조회는 **W-12**가 붙인다.
- **🟡 W-17 항목 — `getDoc` 캐시 폴백.** (W-05 §9 · W-05 지시서 §0.3)
  인증 판정 시 캐시 폴백 때문에 **조회 실패가 "문서 없음"으로 보일 수 있다.**
  `getDoc()`은 서버 실패 시 로컬 캐시로 떨어지고, 캐시가 "문서 없음"을 들고 있으면
  에러가 던져지지 않고 `exists() === false`가 반환된다. W-04 §4-3의 분기는 옳지만
  실제 `permission-denied`에서 안 탈 수 있다 — 활성 부원이 가입 신청 화면으로 튕긴다.
  **지금 없앨 수 없다.** 그 폴백이 곧 오프라인 지원(EC-01)이다.
  W-17에서 `getDocFromServer` 우선 + 실패 시 캐시 같은 전략을 판단한다.
  이 위험이 실현되면 W-05 §7의 `permission-denied` 문구 문제도 함께 사라진다. 두 항목을 같이 봐야 한다.
- **실측 방법(W-05).** `vite preview`가 SPA 폴백을 하므로 **모든 경로를 실제 URL 직접 진입**으로 쟀다.
  `status`·`role` 주입은 임시 `ProbeAuthProvider`가 맡았고(AuthContext를 임시 export),
  측정 후 4곳 전부 되돌렸다. **프로브 제거 후 빌드 산출물 해시가 도입 전과 같은 것이 제거의 증거다.**
- W-01 착수 시 원격 저장소가 비어 있지 않아(커밋 27개) 사용자 선택에 따라 히스토리를
  리셋하고 v0.0.1 단일 커밋으로 시작했다.
  기존 원격 히스토리 백업: `바탕 화면/SunDO_remote_backup_20260820.bundle`
  (복원: `git clone SunDO_remote_backup_20260820.bundle`)
- `design/index.html`은 번들 아티팩트라 마크업이 JSON 문자열로 인코딩돼 있다.
  CSS를 꺼내려면 이스케이프를 2단계 해제해야 한다. 방법은 `reports/W-02.md` §5 서두 참조.

  확장이 연결돼 있지 않았다. 헤드리스 Chrome을 CDP로 직접 구동해 같은 측정을 했다

    `Emulation.setFocusEmulationEnabled`를 켜야 blur 검증을 실측할 수 있다.
