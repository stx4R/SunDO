## 2. 🔴 App Check — 등록 · 디버그 토큰 · 시행

| 층 | 무엇 | 상태 |

| ② **등록·모니터링** | 콘솔이 토큰을 **집계한다** | 🔴 **PM 미완료 — §2.2** |

⚠ 🔴 **지금은 `VITE_RECAPTCHA_SITE_KEY`가 비어 있어 App Check가 아예 초기화되지 않는다.**
앱은 정상 동작하고 콘솔에 `[SunDO] VITE_RECAPTCHA_SITE_KEY가 없어 App Check를 건너뜁니다.`
경고 1줄만 남는다(실측 — `reports/W-22B.md` §4.1).
**§2.2가 끝나고 키를 넣어 재배포해야 ①이 실제로 산다.**

### 2.2 ② 콘솔 등록 — 절차 전문

1. Firebase 콘솔 → 프로젝트 **`sundo-dev-8ef38`** → 좌측 메뉴 **빌드 → App Check**
2. **앱** 탭 → 웹 앱(`SunDO`)의 **등록** 클릭
3. 공급업체에서 **reCAPTCHA v3** 선택
4. reCAPTCHA 사이트 키가 없으면 화면의 링크로 **새로 만든다**
   - 도메인에 🔴 **`sundo-dev-8ef38.web.app`** 을 넣는다
   - ⚠ **로컬 개발을 하려면 `localhost`도 넣는다**
5. **사이트 키**를 복사해 프로젝트 루트의 **`.env.local`** 에 넣는다
   ```
   VITE_RECAPTCHA_SITE_KEY=<여기에 붙여넣기>
   ```
   🔴 **`.env.local`은 커밋되지 않는다**(`.gitignore`). 커밋되는 것은 `.env.example`의 빈 줄뿐이다.
6. **토큰 수명(TTL)** 은 기본값을 그대로 둔다. 🔴 **줄이면 요청이 늘고 과금이 는다.**
7. 다시 빌드·배포한다 — `npm run build` → `npx firebase deploy --only hosting --project sundo-dev-8ef38`
8. 🔴 **확인** — App Check → **API** 탭 → **Cloud Firestore** 행의 **요청 지표**에
   요청이 잡히기 시작해야 한다. 🔴 **이것이 ①이 실제로 붙었다는 유일한 증거다.**

- [ ] 등록 완료 · 사이트 키를 `.env.local`에 넣었다
- [ ] 재배포했다
- [ ] 🔴 **요청 지표에 요청이 잡힌다**

### 2.3 디버그 토큰 — 로컬 개발용

로컬(`npm run dev`)에서는 reCAPTCHA가 성립하지 않으므로 **디버그 토큰**이 필요하다.
코드는 개발 빌드에서만 `FIREBASE_APPCHECK_DEBUG_TOKEN = true`를 세우고,
**브라우저 콘솔이 토큰을 한 번 찍어 준다.**

1. `npm run dev` → 브라우저 개발자 도구 콘솔에서 `App Check debug token: <UUID>` 를 찾는다
2. Firebase 콘솔 → App Check → 앱 → 웹 앱의 **⋮ → 디버그 토큰 관리** → **디버그 토큰 추가**
3. 그 UUID를 붙여넣고 이름을 적는다(예: `유이준 로컬`)

🔴 **토큰 문자열을 코드·`.env.example`·커밋에 적지 마라**(§14.5 12번).
저장소 전체 확인: `git ls-files | xargs grep -l "<토큰>"` 이 **0건**이어야 한다.
🔴 **기기가 바뀌면 토큰도 바뀐다.** 남는 토큰은 지워라 — 지우지 않으면 **영구 우회로**가 된다.

- [ ] 디버그 토큰 등록 · 이름 기재
- [ ] 🔴 저장소에 토큰 문자열 0건

### 2.4 🔴 ③ 시행(enforce) — **이 회차에서 켜지 않는다**

## 4. 승인 도메인 정리 · `localhost` 제거 판단

W-21이 `authDomain`을 `…firebaseapp.com` → **`…web.app`** 으로 바꾼 뒤의 잔재다.

**보는 곳** — Firebase 콘솔 → Authentication → **설정** → **승인된 도메인**
그리고 Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 → **승인된 리디렉션 URI**

| 도메인 | 판단 |
| --- | --- |
| `sundo-dev-8ef38.web.app` | 🔴 **반드시 남긴다** — 현재 `authDomain`이다 |
| `sundo-dev-8ef38.firebaseapp.com` | 옛 `authDomain`. 🔴 **아직 지우지 마라** — 롤백 대상 릴리스(`v0.14.0`)가 이 값을 쓴다 |
| `localhost` | 🔴 **지우면 로컬 개발의 OAuth가 즉시 죽는다**(W-04 §3). **판단 기준은 「개발이 끝났는가」이고, 회차가 남아 있으면 남긴다** |

⚠ 🔴 **`redirect_uri_mismatch`는 브라우저 탭 로그인까지 막는다.** 지우기 전에 반드시 W-21 §1을 읽어라.
