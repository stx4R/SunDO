## 4. 판단이 필요했던 지점과 근거

### 4.1 원격 저장소가 비어 있지 않았다 — 사용자 확인 후 진행

§0은 "레포지토리만 생성된 빈 상태"를 전제했으나, 실제 원격 `main`에는 커밋 27개
(2026-08-17 ~ 08-20, 전부 `Yijun Yoo` 계정)와 `LICENSE`(MIT) · `README.md` ·
`index.html`(2.83MB 오프라인 프로토타입)이 있었다. §5.1-4에 따라 코드를 쓰기 전에
멈추고 §7 형식으로 보고했다.

- 사용자 선택: **B — 리셋 (force push)**
- 실행 전 안전장치: 원격 전체 히스토리를 번들로 백업했다.
  `바탕 화면/SunDO_remote_backup_20260820.bundle` (1.6MB, 27개 커밋 + 모든 ref)
  복원 방법: `git clone SunDO_remote_backup_20260820.bundle`
- 유의점(해소됨): 원격 `index.html`(2,832,995B)과 로컬 `design/index.html`(2,832,602B)은
  **서로 다른 파일**이며 원격 쪽이 더 나중 커밋이었다. 이를 사용자에게 확인한 결과
  **디자인 원본은 `design/index.html`로 확정**되었다(2026-08-20). 원격본은 백업 번들
  안에만 남으며 채택하지 않는다. CLAUDE.md의 "최신본 채택" 규약을 이 파일에 적용해
  원격본을 다시 꺼내오지 않는다.

### 4.2 폰트 — CDN 채택 (사용자 확인)

`public/fonts/`에 Spoqa Han Sans Neo TTF 5종(Thin~Bold)이 이미 있었으나, §2 고정값과
PRD §7.1이 모두 CDN을 지정하므로 사용자 확인 후 CDN을 채택했다.
`https://cdn.jsdelivr.net/gh/spoqa/spoqa-han-sans@latest/css/SpoqaHanSansNeo.css`
(응답 200 확인, 실제 폰트 로드까지 검증 완료).
로컬 TTF 5종은 현재 미사용 상태로 남아 있다. → **§5 사용자 확인 필요 항목 2번**

### 4.3 PRD 파일명 — CLAUDE.md를 실제 파일명에 맞춤 (사용자 확인)

지시서 §4 원문은 `docs/SunDO_PRD_v1.0.md`를 참조하지만 실제 파일은 `docs/SunDO_PRD.md`다.
사용자 확인 후 사용자 파일을 건드리지 않고 `CLAUDE.md`·`docs/PROGRESS.md`의 표기를
`docs/SunDO_PRD.md`로 맞췄다. §4 나머지 내용은 원문 그대로다.

### 4.4 `tsconfig.app.json` 추가 — §3 구조에서 벗어남

§3은 `tsconfig.json`과 `tsconfig.node.json`만 나열하지만, 현재 Vite `react-ts` 템플릿은
`tsconfig.json`을 project references 진입점으로만 쓰고 실제 컴파일 옵션을
`tsconfig.app.json`에 둔다. 이 파일을 지우면 `tsc -b`가 `src/`를 컴파일하지 않아
DoD #1이 깨진다. §3이 구버전 템플릿 레이아웃 기준으로 작성된 것으로 판단해 유지했다.
파일 1개 추가 외에 §3과의 차이는 없다.

### 4.5 `strict: true` 명시적 추가

§2는 `strict: true`를 고정값으로 요구하는데, 현재 Vite 템플릿의 `tsconfig.app.json`·
`tsconfig.node.json`에는 이 옵션이 **없었다**(`noUnusedLocals` 등 개별 옵션만 존재).
템플릿을 신뢰하지 않고 두 파일 모두에 `"strict": true`를 명시했다.

### 4.6 `.gitignore`에 1줄 추가

§3의 "최소 항목"을 모두 넣은 뒤 `.claude/settings.local.json` 1줄을 추가했다.
이 파일은 로컬 권한 설정으로, 공개 저장소에 올라가면 머신별 설정이 충돌하고
불필요한 정보가 노출된다. "최소 항목"이라는 표현을 하한으로 해석했다.

### 4.7 스캐폴딩 생성 방식

작업 폴더에 `docs/` `design/` `public/fonts/` 등이 이미 있어 `npm create vite`가
"기존 파일 삭제" 프롬프트를 띄우는 상태였다. 사용자 파일이 삭제될 위험을 피하기 위해
임시 폴더에 생성한 뒤 필요한 파일만 복사했다. 결과는 §5.2가 요구한
"현재 폴더에 생성, 하위 폴더 안 팜"과 동일하다.

## 5. 사용자 확인이 필요한 사항

1. ~~**원격 프로토타입 `index.html`의 처분**~~ — **해소됨(2026-08-20).**
   디자인 원본은 `design/index.html`로 확정. 백업 번들 안의 원격본은 채택하지 않는다.
2. **`public/fonts/` TTF 5종** — 현재 미사용이다. 오프라인 PWA(PRD의 Workbox 항목)
   단계에서 CDN 대신 로컬 `@font-face`로 전환할지 결정이 필요하다. 그때까지 그대로 둔다.
3. **`README.md` · `LICENSE`(MIT) 복구 여부** — 리셋으로 원격에서 사라졌다.
   다시 올릴 계획이면 어느 작업 단계에 넣을지 지정해 달라.
