### 1-3. §2.3 정렬 키 등가성 — `orderBy('number')`가 `studentNo` 오름차순과 같다

**증명.** DR-01이 `studentNo = String(grade) + pad2(classNo) + pad2(number)`이고, S5의 질의는
`academicYear`·`grade`·`classNo`를 **등식으로 고정**한다. 그 집합 안에서 `studentNo`의 앞 3자리는 상수이고
뒤 2자리는 `pad2(number)`다. `pad2`는 1~99 구간에서 **단조 증가**하므로(자릿수가 고정되어 사전순 = 수치순)
`number` 오름차순과 `studentNo` 사전순 오름차순은 **항등**이다.

**실측**(DoD 13) — 스텁 12건을 `[11,3,7,1,12,5,9,2,8,4,10,6]` 순서로 넣었다.

| 항목 | 값 |
| --- | --- |
| 스텁 입력 순서 | `20311 20303 20307 20301 20312 20305 20309 20302 20308 20304 20310 20306` |
| 화면 출력(활성 9건) | `20301 20302 20303 20304 20305 20306 20307 20308 20309` |
| `[...출력].sort()` | 동일 |
| 판정 | `identical: true` |

질의 로그: `students:academicYear+grade+classNo|orderBy=number asc` — **`isActive` 없음.**

## 4. 판단이 필요했던 지점

### 4-1. 🔴 QA-11-01 — `1f` 원문이 `sticky`와 양립하지 않았다 (착수 전 확인)

**무엇이 문제였나.** §8.5.4 T-03은 「헤더 고정, 리스트만 스크롤」이고, 지시서 §3.2는 이것을
`position: sticky`로 만들라고 못 박았다(중첩 스크롤 금지 · DoD 16). 그런데 §2.4에서 읽은 원문은 이랬다.

- `1f`의 리스트 컨테이너는 `flex:1; overflow:hidden` — **스스로 잘라내는 상자**다. 페이지에는 스크롤이 없다.
- `20g`(S-terms, 최신 판본)도 같은 구조다 — 헤더는 배경이 없고, 스크롤은 **유리 패널 안쪽**에 있다.
- 즉 **디자인은 「고정 헤더 + 스크롤 본문」을 항상 패널이 스스로 자르는 방식으로 푼다.** 배경 없는 헤더 뒤로
  콘텐츠가 지나가는 상황을 한 번도 만들지 않았다.
- 단일 스크롤 + `sticky`로 바꾸면 그 상황이 처음 생긴다. **가림막이 필요한데 시안이 없다.**
- §20.7.1 **OV-05**가 「신버전 시안이 필요하면 사용자에게 먼저 요청한다. 임의로 새 디자인을 지어내지 마라」로
  못 박고 있어 **코드를 쓰기 전에 멈추고 물었다.**

**넘긴 선택지 3개.**

| 안 | 내용 | 비용 |
| --- | --- | --- |
| **A (채택)** | `sticky` + `.dock`과 같은 유리 띠 | design에 없는 표면 1개 신설. 되돌리기 = CSS 1블록 |
| B | 헤더 고정을 버리고 페이지 전체 스크롤 | `6a`(최신 채택본)가 실제로 그 구조다. 새 표면 0개지만 **T-03을 버린다** |
| C | 리스트에 자체 스크롤(`1f` 원문) | W-09의 단일 스크롤 계약 파기 + DoD 16 수정 |

**st4R 회신: A.** 값도 함께 확정됐다 — `position:sticky; top:0; background: rgba(255,255,255,0.6);
backdrop-filter: blur(22px) saturate(170%)`.

**왜 그 값인가.** 앱에서 **스크롤 콘텐츠 위에 뜨는 표면은 `.dock` 하나뿐**이고(`--color-sundo-control`
= `rgba(255,255,255,0.6)` + `blur(22px) saturate(170%)`), 새 색·새 알파를 만들지 않고 그 어휘를 그대로 가져왔다.
`margin: 0 -22px` + `padding: 0 22px`로 `AppShell`의 좌우 패딩을 상쇄해 띠를 스테이지 끝까지 잇는다.

### 4-2. 🔴 `sticky`가 상단 여백을 먹지 않는다 — 실측으로 확인했다

착수 시점의 걱정은 「`top: 0`이면 고정된 순간 헤더가 스크롤 영역 맨 위로 붙어 **safe-area(노치) 아래로 파고든다**」였다.
`AppShell`이 상단 여백 단독 소유자라(§0.4) 화면에서 보정하면 계약을 깨는데, 보정하지 않으면 기기에서 깨질 것 같았다.

**실측 결과 그런 일이 없다.** 브라우저는 스티키 제약을 **스크롤 영역의 패딩 가장자리** 기준으로 잡는다.

| 구성 | `AppShell` `padding-top` | 헤더 `y` (`scrollTop 0`) | 헤더 `y` (`scrollTop 400`·`800`) |
| --- | --- | --- | --- |
| 기본 | `26px` | `26` | **`26`** |
| safe-area `top:59` | `85px` | `85` | **`85`** |
| safe-area + 배너 | `26px`(배너가 safe-area를 먹음) | `141` | **`141`** |

세 구성 모두 **스크롤 전후 `y`가 완전히 같다.** DoD 15의 「헤더 `y` 불변」이 문자 그대로 성립하고,
노치 문제도 발생하지 않으며, **화면이 여백을 다시 계산할 필요가 없다.** CSS 주석에 이 실측을 남겼다.

**리스트 컨테이너에 `overflow:hidden`을 옮기지 않은 것**도 이 구조 때문이다(§3-1 #27).
`1f`에서 그 선언은 `flex:1` 패널을 자르기 위한 것인데, 흐름 안에서 자라는 컨테이너에 걸면
**잘라서는 안 될 것을 자를 위험만** 남는다. 상단 `6px` 패딩이 이미 눌림 배경을 둥근 모서리 안쪽에 가둔다.

### 4-3. S4 빈 상태에 아이콘을 넣지 않았다

§20.7이 빈 상태를 `6e`·`6f`·`6h`·`6i`로, 에러를 `6j`·`6k`로 **화면을 가리지 않고** 채택하므로

## 8. W-12 (S6 기록 작성 시트)에 넘길 전제

### 8-1. 🔴 행 탭이 시트를 여는 **정확한 접합 지점**

`src/screens/ClassStudents.tsx`의 `handleStudent`다. **지금은 인자가 이벤트 하나뿐이다.**

```tsx
// 현재 (W-11) — ClassStudents.tsx:110 부근
const handleStudent = (event: React.MouseEvent<HTMLButtonElement>) => {
  if (tappingRef.current) return
  tappingRef.current = true
  spawnSparkle(overlayRoot, event.clientX, event.clientY)   // ← W-12는 이 다음 줄에 시트를 연다
  window.setTimeout(() => { tappingRef.current = false }, 0)
}

// 호출부 — 학생마다 같은 핸들러를 쓴다. 학생을 넘기려면 여기도 바꿔야 한다.
<button type="button" className="srow" onClick={handleStudent}>
```

**W-12가 해야 하는 것 3가지.**

1. 시그니처를 `(student: Student, event: React.MouseEvent<HTMLButtonElement>)`로 넓히고 호출부를
   `onClick={(event) => handleStudent(student, event)}`로 바꾼다.
2. `spawnSparkle(...)` **바로 다음 줄**에 시트 오픈을 넣는다. §8.5.4 T-02가 `sparkle` → 딤 0.3s +
   시트 0.38s를 **같은 트리거**로 규정한다.
3. 🔴 **빗장 해제 시점을 다시 정해야 한다.** 지금은 `setTimeout(…, 0)`으로 다음 태스크에 푼다(§4-7).
   시트가 열리면 **시트가 닫힐 때 푸는 것**이 맞다 — 열려 있는 동안 뒤의 다른 행이 눌리면 안 된다.

**교사 계정은 아예 `<button>`이 아니라 `<div>`로 렌더된다.** 시트를 붙일 때 `isTeacher` 분기를
그대로 두면 T-04(교사 행 탭 = 무동작)가 자동으로 지켜진다.
