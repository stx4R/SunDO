### 3.3 P-0 — 🔴 PWA standalone 로그인 무한 루프

**관측** — iOS·Android **양쪽**. 브라우저 탭에서는 정상.

🔴 **공통점이 단서다** — 브라우저는 `signInWithPopup`이 열려 리다이렉트 경로를 타지 않는다.
standalone은 팝업이 막혀 `signInWithRedirect`로 폴백하고(§9.1 · EC-30), **그 경로는 한 번도
실물로 검증된 적이 없다** — `reports/W-19.md` §5의 3번이 미측정으로 남은 그 자리다.

⚠ **시점 논증을 쓰지 마라.** 「W-19에서는 됐는데 W-20에서 깨졌다」는 근거가 없다. W-19에서도
미측정이었다.

**🔴 가장 싼 판별 실험을 먼저 하라**

기기에서 서비스 워커 해제(`database_ToDo/W-20.md` §1.2 — **Unregister + 사이트 데이터 삭제**)
→ standalone 재설치 → 로그인.

| 결과 | 확정 |
| --- | --- |
| **로그인이 된다** | 🔴 **SW가 리다이렉트 내비게이션을 가로챈다**(가설 1) |
| 여전히 루프 | SW 무관. 가설 2·3으로 |

⚠ Unregister만 하고 사이트 데이터를 안 지우면 캐시가 남아 실험이 오염된다.

**가설 3개**

| # | 가설 | 확인 |
| --- | --- | --- |
| 1 | 🔴 **SW가 OAuth 리다이렉트를 가로챈다** | `public/sw.js`의 내비게이션 분기가 `/__/auth/**`를 잡는가. 🔴 **`fetch()`는 기본 `redirect:'follow'`라 302 연쇄를 따라간 뒤 `response.redirected === true`인 응답을 돌려주는데, 그것을 내비게이션에 `respondWith`하면 브라우저가 거부한다.** OAuth는 302 연쇄가 본체다. W-20 §1.4 표는 「Firestore는 가로채지 않음」만 적었고 **Auth는 적혀 있지 않다** |
| 2 | **`getRedirectResult()` 호출 시점** | `grep -rn "getRedirectResult" src/` → **0건이면 그것이 원인이다.** 부른다면 `onAuthStateChanged` 구독·라우팅 판정보다 먼저인가 |
| 3 | **`firebase.json`의 SPA rewrite가 `/__/**`를 삼킨다** | 배포본에서 `/__/auth/handler`를 직접 열어 확인 |

### 3.4 P-1 — S5 리스트가 헤더와 겹친다

**관측** — 스크롤하면 행이 `학생 목록` 헤더 **뒤로 비쳐** 지나간다. 사용자는 「리스트 영역

**관문 ①** — 🔴 **W-11의 QA-11-01이 이 자리를 이미 판단했다.** `1f` 원문이 `sticky`와 양립하지

화면 12종이 함께 움직인다.

⚠ **`ScrollRootContext`·`usePullToRefresh`가 스크롤 주체를 전제한다**(W-10·W-13).
스크롤 주체를 바꾸면 **당겨서 새로고침이 함께 깨진다.** 관문 ③에 반드시 적어라.

### 3.5 P-2 — Shiny 효과가 텍스트 상자에 걸린다

**관측** — `기록 저장` 버튼에서 글자가 아니라 **직사각형**이 반짝인다.

**전수 조사가 먼저다.** 🔴 「해당 웹의 **모든** Shiny 효과」가 요구다.

1. `grep`으로 관련 클래스·키프레임을 전부 찾아 **표로 보고**하라(선택자 · 소비자 화면 · 현재 형태)
2. 🔴 **대상과 비대상을 갈라라** — `.skel`(스켈레톤)의 shimmer는 **블록**이 맞다.

**고치는 방향** — 텍스트에만 걸려면 `background-clip: text`(+ `-webkit-` 접두)와

**글자가 통째로 사라진다.** `@supports`로 감싸고 폴백을 남겨라. 반드시 실기기에서 확인하라.

⚠ **`prefers-reduced-motion`에서 정지하되 최종 상태는 같아야 한다**(W-03B §4-3 규약).
지금 그렇게 돼 있는지 확인하고 유지하라.

**관문 ③** — 소비자가 여러 화면이면 **전부** 전/후 computed를 대조하라.
